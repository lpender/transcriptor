# Deck v3 — five slides (2026-10-04)

**This is a decision deck, not a fundraising deck.** The honest conclusion of
this run is that Tablework should not raise, and the founder did not ask to.
What follows is what he should decide this month.

---

## 1. What is true

A working, live, multi-user rehearsal product, built in fifteen days of
evenings: shared character voices, per-actor line drilling, the director's
off-book view, billing, auth, and an MCP server a director's AI administers.
One production uses it — his own. **No revenue. No second customer.**

## 2. What is not true

- **There is no moat.** The clip cache is global and real (258 clips, one
  play), but the hash includes the voice id, so it only compounds if companies
  converge on the same casting, which nothing encourages. A funded competitor
  reproduces it in days for a few hundred dollars. `moat-measured.md`.
- **$1 a seat cannot pay for a customer.** A cast of ten is $10 a month and a
  production closes in six to eight weeks: **LTV $20–30**. There is no
  acquisition budget at that number — not a small one, none.
- **Commits are not traction.** 342 of them are a cost.

## 3. The one change that matters

**Sell the record to the organisation, not the drill to the cast.** The school
department or community theatre that programmes four shows a year has a budget
line, a next show, and a reason to care who went off book last time. Same
code. A season view is the only new screen, and the data for it is already in
the database.

This is a pricing and positioning decision, not a build.

## 4. The arithmetic that decides it

At $1/seat/month this is a tool. At a few hundred dollars a season to an
institution it is a small business, if — and only if — the institutional buyer
exists and can be reached by a founder whose network is cast-shaped.

**Nobody in this run could size the institutional buyer from public sources
inside the window** (see `tam-arithmetic.md`). That is the first thing to find
out, and it costs five phone calls, not a quarter.

## 5. The decision, and the four things that answer it

**Do not raise. Do not quit. Do not build another feature.** With under six
months of runway and a full-time job, the correct posture is free optionality:
this stays a side build until a stranger pays for it.

Inside a month, beside the job:

1. Ask five directors what the department actually buys, and who signs.
2. Instrument the invite link — it is the only acquisition mechanic that
   exists, and it is unmeasured.
3. Charge the current production. One paying stranger beats the whole deck.
4. Read the PIIA clause before any of the above becomes commercial.

If (1) finds a budget and (2) shows actors starting their own productions,
there is a business here at the organisation price. If neither, this is a
very good tool for the show he is in, and that is a legitimate place to stop.
